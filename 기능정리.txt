소크 React 웹앱 기능 정리
=========================

1. 서비스 목적
사진과 가게 정보를 한 번 입력하고 인스타그램, 페이스북, 구글 비즈니스,
네이버 플레이스, 당근에 사용할 홍보 문구를 채널별로 만들어 관리하는 웹앱입니다.

2. 로그인과 저장
- 이메일을 입력하면 사용자별 작업 공간이 열립니다.
- 별도 비밀번호나 이메일 인증은 없습니다.
- 가게 정보와 캠페인은 현재 브라우저의 localStorage에 저장됩니다.
- 같은 브라우저에서 같은 이메일로 들어오면 저장한 캠페인을 다시 볼 수 있습니다.

3. 가게 정보
- 가게 이름, 업종, 주소, 전화번호, 영업시간을 입력합니다.
- 입력한 가게 이름, 업종, 주소는 생성 문구의 가게 안내와 해시태그에 사용됩니다.

4. 새 캠페인 제작
- 홍보 사진을 올리면 1080×1350(4:5) 비율의 JPEG로 자동 정리합니다.
- 캠페인 이름과 메뉴, 가격, 이벤트 기간 등 원본 정보를 입력합니다.
- 문구를 만들 채널을 선택합니다.
- “AI 채널 문구 만들기” 버튼을 누르면 채널 말투에 맞는 초안이 생성됩니다.
  현재 버전은 브라우저 안의 템플릿으로 생성하며 외부 AI API를 호출하지 않습니다.

5. 채널별 미리보기
- 생성된 문구를 직접 수정할 수 있습니다.
- 처음 생성된 문구로 복원할 수 있습니다.
- 글을 클립보드에 복사하고 사진을 내려받을 수 있습니다.
- 실제 게시를 마치면 “게시했다면 체크”로 완료 상태를 기록할 수 있습니다.
- 필요 없는 채널 결과는 개별 삭제할 수 있습니다.
- 요청에 따라 “내 페이지 열기”, “자동 게시”, “복사 후 게시” 버튼은 없습니다.

6. 캠페인 관리
- 여러 채널 결과를 하나의 캠페인으로 묶어 저장합니다.
- 저장 목록에서 제목, 저장 시각, 채널 수를 확인합니다.
- 상세 화면에서 문구 수정, 복사, 사진 다운로드, 게시 완료 표시가 가능합니다.
- 개별 채널 또는 캠페인 전체를 삭제할 수 있습니다.

7. 파일 구성
- src/App.jsx: 로그인, 상태, 저장, 캠페인 흐름을 연결합니다.
- src/components: 화면을 역할별 컴포넌트로 나눕니다.
- src/lib/storage.js: localStorage 읽기와 쓰기를 담당합니다.
- src/lib/campaign.js: 채널 문구 초안을 만듭니다.
- src/lib/image.js: 사진 크기 조정과 다운로드를 담당합니다.
- src/styles.css: 모바일과 데스크톱 반응형 디자인입니다.

8. 개발과 배포
- npm install: 필요한 React/Vite 패키지를 설치합니다.
- npm run dev: 개발 서버를 실행합니다.
- npm run build: dist 폴더에 배포 파일을 만듭니다.
- npm run preview: 만들어진 dist 결과를 로컬에서 확인합니다.
- GitHub Pages, Vercel, Netlify 등 정적 호스팅에 dist 폴더를 배포할 수 있습니다.
